# AI 拷问官

一个**只问不答**的对抗式质检智能体：贴进或上传你自己写的东西，它按「事实 → 依据 → 前提」三层追问，最后给你一张卡点报告——哪句话站不住、缺的是什么。

它不讲解、不给答案、不评价、不鼓励。学生写报告、做汇报、准备答辩时，缺的往往不是又一个帮你写完的工具，而是一个在交上去之前证明你没懂的东西。

## 怎么用

打开页面 → 选场合 → 贴入材料或直接上传（Word / PPT / Excel / PDF / 纯文本，50–8000 字）→ 逐层作答 → 看卡点报告。报告可复制或下载为 Markdown。

## 两种运行态，界面如实标注

| 态 | 说明 |
| --- | --- |
| 离线题库版（默认） | 不发出任何网络请求，问题来自内置规则题库。断网可用 |
| 模型在环 | 点页脚「追问引擎」，填入你自己的 OpenAI 兼容接口（地址 / 模型名 / 密钥），问题由模型现场生成。密钥只存在当前标签页，关掉即失效 |

材料只在你的浏览器里处理；只有在你主动启用模型态时，材料才会发给你自己填的那个接口。

## 它不做什么

不判分、不代写、不替代教师评价；不覆盖所有学科；不保证还原文档版式（只取文字）。

## 技术

React 19 + Vite 7 + TypeScript。入口是单个 HTML（约 290 KB），**Word / PPT / Excel / 纯文本在离线双击版里都能用**。

**PDF 是例外**：解析器（pdf.js，约 1.7 MB）按需加载，所以需要联网、且需要同目录下的 `assets/`。离线双击时选 PDF 会给出明确提示，其余格式不受影响。
